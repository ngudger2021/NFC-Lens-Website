What it does

Built as a learning and inspection tool. It shows what a card exposes during a contactless read and explains each piece of data.

Card-style summary

The card's network, issuing country, masked number, cardholder name and expiry, drawn like a real card.

Flip to the back

Tap the card to see the back: dates, card sequence, issuing country and application details.

Plain-English fields

Every EMV tag is grouped (card data, application, processing, device). Tap any field to see what its tag is for.

Masked by default

Sensitive values stay hidden until you turn on Reveal. Reports and the live log follow the same setting.

Demo mode

Explore with fictional card data, without any reader or phone NFC hardware.

Reports you control

Export a plain-text report to a file you choose. Nothing is uploaded anywhere.

Privacy and limits

Read this before you use it on real cards.

It's an inspection tool, not a payment app. It never authorises a payment, never writes to a card, and never sends data anywhere. Use only cards you're authorised to inspect.

Real card reads are still being tested on hardware. Contact-only chip cards, DESFire cards and cards that require a PIN aren't supported.

Build it yourself

Both apps share one protocol library, NFC-Lens-Core, included as a git submodule. Each repository's README has full build steps.

  1. Clone with submodules. git clone --recurse-submodules the app you want.
  2. Install the SDK. Windows needs the .NET 10 SDK. Android also needs the Android SDK and a JDK, which build.ps1 can download.
  3. Build. Run dotnet build for Windows, or .\build.ps1 for an Android APK.
